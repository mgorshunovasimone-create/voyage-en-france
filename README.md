# Voyage en France

Интерактивная RPG-карта для изучения французского: путешествие по регионам Франции, культурные квесты, круассаны как валюта.

## Структура

```
index.html            точка входа
css/styles.css        все стили
js/app.js             вся логика (карта, попапы, портал, хаб квестов)
assets/
  map/
    france-map.png      вырезка карты Франции (с прозрачным фоном), без потерь — исходник, сайтом не грузится
    france-map.webp     та же карта в WebP (~260 КБ) — для экранов от 700px
    france-map-mobile.webp  уменьшенная до 1000px (~150 КБ) — для телефонов
    water-loop.mp4       зацикленное видео-фон (море/небо)
    water-poster.webp    кадр-постер видео + фон body (water-poster.jpg — исходник)
  heroes/                фото-обложки регионов: *.webp (1200px) — экран города, small/*.webp (360px) — превью
                          под точкой на карте; *.jpg — исходники, сайтом не грузятся (кроме occitanie.jpg)
  themes/                21 фото тем квестов (карточки по 3 на город); для 4 крупных есть сжатые .webp,
                          сайт берёт их, .jpg рядом — исходники
  icons/                 5 иконок-стикеров (.webp; .png — исходники) для рубрик квестов (наблюдение/меню/новости/журнал/спор)
  quests/                15 самостоятельных HTML-страниц заданий — грузятся в <iframe>
                          по требованию, только когда пользователь открывает конкретную иконку
```

## Как это работает (важное для скорости загрузки)

- **Начальная загрузка** = только `index.html` + `css/styles.css` + `js/app.js` + одна из `assets/map/france-map*.webp` (выбирается по ширине экрана; пока грузится — заставка)
  (видео-фон начинает грузиться только после того, как карта показана, чтобы не отнимать у неё скорость).
- **Превью городов** (фото тем + маленькая обложка, ~1 МБ на все города) подгружаются заранее,
  сразу после появления карты — чтобы при касании точки на телефоне картинки уже были.
  Полная обложка города начинает грузиться при первом касании/наведении.
- **Остальные фото** запрашиваются браузером только когда реально показываются
  (наведение на город, вход в город, открытие хаба квеста) — `img.src` выставляется из JS в момент
  необходимости, а не заранее. У картинок в карточках тем стоит `loading="lazy"`.
- **Файлы заданий** (`assets/quests/*.html`) — это полноценные отдельные HTML-страницы.
  Раньше (в версии-артефакте) они были закодированы в base64 прямо внутри JS и весь файл весил
  больше 16 МБ. Теперь `iframe.src` — это просто путь к файлу; браузер запрашивает его
  (и кэширует) только в момент открытия конкретной иконки в хабе квеста.

## Деплой

Это статический сайт — просто выложить папку целиком на любой статический хостинг
(GitHub Pages, Netlify, Vercel, Cloudflare Pages, обычный nginx/Apache). Никакой сборки не требуется.

Единственное, за чем стоит следить: сервер должен отдавать корректные MIME-типы для `.mp4`, `.png`,
`.jpg` и `.html` — это делают все перечисленные хостинги по умолчанию.

## Прогресс игрока

Прогресс (открытые города, круассаны, пройденные этапы квестов) хранится в `localStorage`
браузера пользователя, ключ `voyage-en-france-state-v5`. Ничего не отправляется на сервер —
бэкенд не нужен.

## На заметку (не готово / условности)

- Только Париж по-настоящему играбелен (3 квеста: кафе, Лувр, дом моды). Клик по любому
  другому городу показывает модалку «скоро».
- Фото тем для городов, кроме Парижа/Бретани/Шато-де-Шантийи, — плейсхолдеры из самой первой
  версии сайта; можно заменить на более качественные при желании (см. `assets/themes/`,
  имена файлов вида `<город>--<слаг-темы>.jpg`).
- Окситания без фото-обложки региона (только у остальных 6 городов есть `assets/heroes/*.jpg`).
